## Consequences for reuse

The relational experiment found useful machinery already present: FIFO and
interval syntax registrations derive whole-term certificates. Both routes retain
the same selected implementation output as their direct proofs. The result
supports using those existing compilers; it does not justify another registry.
[#383](https://github.com/VladimirMarko/conaled/issues/383) tests the next missing
contract, where result relations depend on related indices. It must inspect
existing indexed interpretation before introducing an interface, preserve chosen
fiber data, and compare complete term-and-type transport with a direct proof.

The probability experiment constructs the semantic model needed by its client.
Random-element closure, function-space evaluation and currying are checked,
as are the measurable source bridge and actual pushforward measures. The shared
and freshly sampled continuous observations have equal marginals but differ on
an event with probabilities 0 and 1/6. The nonlinear squaring interpretation and
correlated polynomial repair preserve their independently specified measures.
This supplies a capability beyond fixed affine closures without requiring an
adapter to the incumbent compiler. It does not supply runtime sampling adequacy,
a general probability object, or general bind. #200 retains those broader model
obligations; they are not prerequisites to use the checked fragment.

The geometric experiment improves the consumer boundary without changing the
mathematical setting. Explicit local data derive coverage and compatibility;
sheaf uniqueness establishes independence from the admitted descriptions. The
old inverse, naturality and group laws remain specializations. The declaration
ledger records supplied data, selectors and transitive axioms. Removing a visible
selector from one API does not by itself make its implementation constructive.

## What this does and does not establish

These tasks use different acceptance contracts. The probability comparison
needed an actual model; the transfer comparison allowed justified reuse of
existing registrations; the geometric task allowed an API refactoring with an
honest dependency ledger. None establishes general agent-productivity gains.
Model construction, source authoring, recurring proof obligations and execution
remain separate costs to measure.

A shared risk remains that small examples hide model assembly and extension
costs. #370 discharges one concrete model-assembly obligation. #382 retains
varying bound bodies beyond the nominal telescope's fixed schema; #383 retains
varying output fibers beyond the fixed-carrier comparison. These are tests of
generality, not reasons to discard the useful bounded results.
