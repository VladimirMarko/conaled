## Differences between the proposals

The contract and alternatives lenses favor an independent associative binary state operation as the next shape. The implementation lens proposes independently supplied FIFO state updates, with existing command execution and old-client preservation as a useful consumer. These tests answer different questions. Binary transport tests changed arity and equation transport; interleaved FIFO commands test usable composition and migration. Neither is established product demand, and neither alone establishes a generic framework's value.

There is a small scope difference concerning units. The alternatives lens proposes an independently supplied unit with its side laws. The contract lens warns against silently making the existing selected state point a unit. Both can be respected: a unit may belong to the new operation package, but equality with the existing point requires an explicit client requirement. The current independent result constant must likewise remain independent of point observation.

Retain the implementation lens's relational FIFO migration control. Its existing simulation theorem needs a relation, not inverse state maps. Requiring exact carrier equivalences would strengthen its assumptions and lose an existing capability. A relational alternative is admissible on its own terms, but cannot silently replace the current invertible-recovery contract.
