# External discovery evidence for #280

This directory retains the discovery briefs and source assessments for
[#280](https://github.com/VladimirMarko/conaled/issues/280). The coordinator
started from local commit `f912d7c`. These notes are research evidence, not
instructions to future agents or completed implementation experiments.

## Method and exposure

Two fresh agents received no conversation fork and were instructed to read only
the common brief and their distinctive author-needs assignment before searching.
They recorded initial queries, source trails, prior conceptual exposure and
access limits. Each reported its initial memo frozen before receiving the
previous assessment or local interfaces. This procedural separation reduces
one source of anchoring; it does not make their training, search engines or
conceptual vocabularies statistically independent.

- [Common brief](common-brief.md).
- [Assumptions and reuse: frozen initial discovery](assumptions-initial.md).
- [Extension obligations: frozen initial discovery](extension-initial.md).
- [Computation supplement](computation-comparison.md), written by the coordinator
  with prior exposure to the shortlist. It follows probability/concurrency gaps
  and is not an independent third discovery track. The agent limit prevented a
  third fresh session. Subsequent local comparison found substantial prior work
  in #199, which the supplement credits explicitly.

The initial memos reproduce the supplied prompts verbatim, including temporary
working paths. Those paths record the procedure; every required artifact is
retained here and no later task needs access to those host paths. Search queries
containing named traditions are visible rather than relabeled as neutral queries.
Full-text inspection at named locators is distinct from an independent proof audit.
