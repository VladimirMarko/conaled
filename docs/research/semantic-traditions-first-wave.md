The result is evidence for this small library seam, not a universal quantitative effect hierarchy. #374 should compare relation-preserving constructions without conflating interval enclosure with metric error; #193 remains the owner of the broader resource comparison.

## A recurring decision check

Compare specifications before comparing machinery. Ask whether both routes retain the same observations, satisfy equally strong assumptions, and receive the same evidential threshold. A missing adapter is not a mathematical obstruction; a shared theorem name is not proof of equivalent capability. Keep independent formulations and negative controls so the incumbent representation cannot define success by itself.

The control review found a concrete blind spot beyond scheduling bias: a substitution proof for pure terms was used on mixed syntax with open runtime continuation parameters. Finite tests passed, but the universal paper argument omitted the actual initializer case. The repair expanded the induction domain and kept closed runtime data separate from open term parameters. Review should track the exact grammar and domain of each reused theorem, including intermediate states.

A remaining shared blind spot is scale of model assembly. Two small clients or one fixed body can demonstrate mathematical feasibility while hiding the cost of adding new observations, dependent bodies or semantic structure. This calls for explicit extension obligations and native comparisons, not a productivity claim from theorem counts or source size.
