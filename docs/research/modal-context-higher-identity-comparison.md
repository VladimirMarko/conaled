## Task M: access under two locks

Fix one mode and the free strict 2-category generated by endomodalities `a`,
`b`, `c` and a 2-cell `α : a ⇒ b`. Its 1-cells are words, composed by
concatenation. Its 2-cells are generated by identities, `α`, vertical composition
and whiskering. In particular, every generating rewrite preserves word length;
there is no 2-cell from the empty word `1` to `b∘c`.

Use the Boolean type `B` and the context

```text
Γ = x : (a∘c | B), y : (1 | B).
locked Γ = Γ, lock b, lock c.
κ = α whiskered by id_c : a∘c ⇒ b∘c.
```

The frozen author argument in the locked context returns the selected pair
`(x^κ, refl(x^κ)) : Σ(z:B). Id_B(z,z)`. Its intended data are the permitted
Boolean and its reflexive certificate. The ordinary variable `y` must remain
unavailable there. This is an abstract modal-access example, not a claim that
these generators already describe cohesion, security clearance or a particular
crisp modality. Those interpretations require their own model and equations.

The paper derivation uses the modal variable rule with exactly `κ`, then the
ordinary reflexivity and dependent-pair rules at the mode. Constant Boolean
formation is stable under the key substitution. The competing expression
`(y,refl(y))` would need a variable-access 2-cell `1 ⇒ b∘c`, which the frozen
mode theory lacks. This rejects that occurrence of `y`; it does not claim that
the result type is uninhabited, since a closed Boolean would also give a pair.

The direct fragment-level contract can instead be stated as factoring the
returned Boolean through the permitted projection
`π : B × B → B`, `π(x,y)=x`. The valid result factors as the identity after `π`.
The forbidden result `y` does not factor: `(false,false)` and `(false,true)`
have the same permitted projection and different requested outputs. This is a
paper noninterference calculation for the frozen two-variable observation,
not a model of the whole MTT calculus. It states why the restriction matters
without pretending that one collapsing interpretation proves syntax adequacy.

## MTT source contract and substitution audit

[Gratzer, Kavvos, Nuyts and Birkedal, *Multimodal Dependent Type Theory*,
v2](https://arxiv.org/pdf/2011.15021v2), 2021-06-01, §§2, 4–7:
Figure 2's variable rule requires a 2-cell from the variable annotation to the
composite trailing locks; types move by the corresponding key substitution.
Theorem 7.1 assumes an MLTT natural model at each mode, a size-preserving
dependent right adjoint for each modality, a natural transformation for each
2-cell, and 2-functoriality of these choices. It constructs an MTT model.
Section 5.3's model morphisms preserve chosen structure strictly. Theorem 6.8's
closed-term canonicity follows under the preceding empty-context lock equation;
it is not a theorem for arbitrary added rules. The base system has intensional
identity, Booleans and a universe. We inspected these technical statements,
not only the abstract. No concrete modal model or implementation is constructed
here, and no unqualified normalization or arbitrary weak-map theorem is inferred.

For Task M, two locks compose as `lock b; lock c = lock(b∘c)` in the context
structure. Replacing this by a merely propositional equivalence would require
explicit coherence and transport in any implementation of the strict source
presentation. The key substitution for `κ` goes from the `b∘c`-locked context
to the `a∘c`-locked context, contravariantly to the 2-cell. A type depending on
`x` must travel through this substitution; discarding the superscript on a
nonconstant type would omit a typing obligation.

A legal substitution for `x` must supply a Boolean term under its declared
`a∘c` access. For example, a fresh variable `z:(a∘c|B)` supplies `z` under
those locks by the identity 2-cell. After substitution, the selected result
uses `z^κ`. Supplying the ordinary variable `y:(1|B)` instead would require
`1 ⇒ a∘c`, again impossible by word length. Thus substitution does not turn
an unavailable variable into an available one. An untyped environment function
that performs this replacement has not established a modal substitution judgment.

The mode author supplies composition, identities, 2-cells, their equations and
the model interpretations. The client supplies the allowed annotations and
uses the resulting variable/substitution rules. The strict mode theory here is
countable and small; this is not a universe-polymorphic collection of all
modalities. The paper term requires no object-language universe, although a full
application of the cited model theorem includes its size-preserving universe
structure. A fragment-specific implementation could avoid that extra structure
only with a separate soundness argument for the restricted fragment.

## What the current representation provides for Task M

The [generated dependent judgments](../../SquareKit/Internal/DependentJudgments/Theory.lean)
separate source derivability from evaluation. Their ordinary contexts,
substitutions and guarded operations are useful foundations, but their existing
signature has no modal annotation, lock word or mode 2-cell access judgment.
Adding a unary term constructor called a modality would not change the
variable rule or make the forbidden substitution fail.

The direct projection proof is adequate for this one observer. Reusing it
through many dependent context extensions would require a stable class of
admissible substitutions and corresponding family/term reindexing. A modal
judgment layer is a plausible way to make those obligations reusable. It is
not necessary to force all ordinary clients to carry mode annotations.

The [checked source boundary](../../Examples/GuardedJudgmentBoundaries.lean)
shows why the distinction must persist: `no_source_equality` rejects reflecting
equality from one decoded valuation into generated source equality. It does
not already prove the modal access theorem. Likewise, guarded definedness of a
raw operation is not the same predicate as permission to use a variable.
An adapter must preserve the generated judgments and add explicit modal
formation/access/substitution rules, rather than silently identify these checks.

## Task H: retain the dependent transport and its higher evidence

Reuse the frozen [#316 consumer](dependent-higher-identity.md), rather than
inventing another higher-model demonstration. For a family `B` over `A`, paths
`p:x=y`, `q:y=z`, and `u:B(x)`, retain

```text
v(p,q,u) = tr_B(q, tr_B(p,u))
η(p,q,u) : Id(v(p,q,u), tr_B(p·q,u))
w(p,q,u) = (v(p,q,u), η(p,q,u)).
```

For `h : Id(p,p')`, the dependent action on `η` has source transported in
`K(p)=Id(v(p,q,u),tr_B(p·q,u))`:

```text
apd_η(h) : Id(tr_K(h,η(p,q,u)), η(p',q,u)).
```

Freeze both substitutions from the existing memo. The comparison must identify
sequential substitution with composite substitution for `w` and `apd_η`, including
the displayed transported source. Merely comparing the first component of `w`
would erase the chosen certificate. Nor can an endpoint equality justify
comparing terms in unrelated fibers without transport.

The first-path control uses the existing integer action: transport by labels
1 then 2 sends 0 to 3; replacing the first path by reflexivity gives 2.
The [generated groupoid client](../../Examples/GuardedGroupoidMemo.lean)
connects the source argument to a constructed ordinary groupoid model. The
[earlier groupoid cases](../../Examples/GroupoidTransport.lean) also retain
arrow labels under an ineffective action, where equal outputs do not imply
equal input paths. These are reusable checked lower-dimensional contracts.

For the higher control, the accepted external #316 source instantiates
`A=K(ℤ,2)` and selects `h=decode 1`, with `encode(h)=1` and `encode(refl)=0`.
Its observed expression is the conjugated dependent path action, retaining
endpoint comparisons, not an unrelated integer label. Replacing that expression
by reflexivity contradicts the integer observation. This is reported external
Agda evidence at its pinned source/library/compiler versions, not a Lean
interpretation. The ordinary groupoid identity family is discrete at the next
level, so it cannot supply this same nontrivial second identity.

## Cubical source contract and equality audit

[Cohen, Coquand, Huber and Mörtberg, *Cubical Type Theory*](https://drops.dagstuhl.de/storage/00lipics/lipics-vol069-types2015/LIPIcs.TYPES.2015.5/LIPIcs.TYPES.2015.5.pdf),
DOI 10.4230/LIPIcs.TYPES.2015.5, §§3–9: Lemma 21 proves interpretation/substitution
compatibility when the interpretations are defined and the substitution domain
matches the context. Theorem 23 gives defined interpretations and preservation
of the listed well-formedness, typing, equality and substitution judgments in
the constructed cubical semantics. Types carry composition structure stable
under dimension substitution. The Russell-universe interpretation in §8.3 uses
two ambient Grothendieck universes. Section 9.1 explains why Path alone lacks
the usual judgmental identity computation, and constructs an Id extension with
marked constant faces and strict reflexive J computation. Its Path equivalence
does not make the two types judgmentally identical. These technical passages
were inspected. This source is a semantic existence route with specific rules,
not an automatic verification of Cubical Agda's implementation or a Lean model.

For Task H, the generic argument needs dependent extension, substitution, Σ,
Id and arbitrary-motive contextual J with its computation and substitution
laws. It does not require a source universe or univalence. The particular
external higher parameter uses more library structure; that structure must not
be confused with premises of the generic argument. Universe assumptions for a
full cubical model are therefore not proved necessary for every possible model
of this smaller fragment.

A cubical interpretation must assign contexts and dependent families, dimension
restrictions and composition; then interpret the generated source rules.
For the existing judgmental J contract it must construct the strict Id extension
or a sound translation preserving that computation. Replacing Id by Path and
asserting that all reflexive transport reduces definitionally is the exact
unsupported law. A propositional path comparison is useful evidence, but it is
not the same source judgment.

The two substitutions must act on all dependent components and their boundaries.
When translating the external source, one also needs the relationship between
its inductive equality and the cubical path representation, including the
reflexivity/basepoint comparisons used by the detector. A carrier equivalence
alone does not establish `encode(refl)=0`. Neither UIP nor Lean's proof-irrelevant
host equality can be used to erase the selected object-language 2-cell and then
advertise preservation of the higher observation.
