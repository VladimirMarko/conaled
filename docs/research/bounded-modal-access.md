# Bounded dependent modal access

For [#375](https://github.com/VladimirMarko/conaled/issues/375),
[the generated fragment](../../SquareKit/Internal/ModalAccess/Fragment.lean)
and [its checked client](../../Examples/ModalAccess.lean) implement Task M from
[the #297 comparison](modal-context-higher-identity-comparison.md). They preserve
its selected Boolean and reflexive certificate, enforce both locks, and prove
substitution and key coherence. Existing ordinary source clients are unchanged.
This is a fragment-specific model, not a model of the whole MTT calculus.

## Source contract and chosen boundary

The primary source is Gratzer, Kavvos, Nuyts and Birkedal,
[*Multimodal Dependent Type Theory*, arXiv:2011.15021v2](https://arxiv.org/pdf/2011.15021v2),
1 June 2021. Section 2 and Figure 2 require a cell from a variable's annotation
to its trailing locks. Section 4's key substitutions act contravariantly on
locked contexts; their equations express functoriality and naturality.
Section 7.2, Theorem 7.1 assumes mode-local MLTT natural models, size-preserving
dependent right adjoints and natural transformations for cells, chosen
2-functorially. Those assumptions yield a full MTT model. We inspected the
variable/key rules and that theorem, but do not instantiate it here.

The weaker construction uses finite contexts of annotated Boolean declarations,
lock words, Boolean constants and negation, identity introduction, and the
selected dependent sum `Σ z : Bool, Id Bool z z`. Identity formation permits
unequal endpoints; its interpretation is a family over environments. There are
no modal type constructors, arbitrary dependent context extensions, identity
elimination, universes or general dependent sums. These omissions remove the
need for dependent right adjoints in this bounded soundness proof. The model
requires no assumed substitution theorem: interpretation and compatibility are
proved recursively for every generated term, then for identity fibers and
selected packages.

The one-mode theory has words in `a,b,c`. `Cell` is generated by identity,
`a ⇒ b`, vertical composition and concatenation. It is a **thin reachability
presentation**: parallel cells live in `Prop` and hence are equal. We do not
claim a formal equivalence to the free strict 2-category presentation in #297.
It retains the selected permitted cell and the length obstruction used there.
Word concatenation is ordinary list concatenation, with its associative/unit
laws; `Cell.interchange` supplies horizontal/vertical coherence in the thin
presentation. This choice cannot test distinctions between parallel keys.

The concrete model is

```text
Env Γ w = (i : Fin n) → Cell (Γ i) w → Bool.
```

A cell `k : u ⇒ v` induces `Env Γ v → Env Γ u` by precomposing each
access cell with `k`. Identity and composition hold as equalities, not merely
as equivalences of contexts. This model stores the accessible values; it is
not a Boolean policy flag attached to an unrestricted evaluator. Two values
of the permitted variable remain distinguishable. The model is intentionally
not claimed to extend to all of MTT's context/lock operations.

## Generated judgments and coherence

`Term Γ w` generates exactly the Boolean rules in this fragment. A variable
requires its actual `Cell (Γ i) w` derivation. `Sub Δ Γ` supplies a generated
term under each declaration's own word, so replacing the permitted variable
by an ordinary variable requires the missing cell even before evaluation.
Substitution recursively applies each occurrence's key to its replacement.

`Term.subst_id`, `Term.subst_comp`, `Term.key_comp` and `Term.subst_key`
prove the source equations. `Env.key_comp`, `Sub.eval_key` and `Sub.eval_comp`
prove the corresponding contravariant semantic coherence. `Term.eval_subst`
is the structural interpretation theorem. None is a field assumed of a model.

`IdTerm s t` is a generated identity witness indexed by both source endpoints.
Its only constructor is reflexivity. `IdFamily s t` interprets the type as
`ρ ↦ PLift (eval s ρ = eval t ρ)`; `IdFamily.subst` and `IdFamily.key`
identify the reindexed families, including their endpoints. The `trueFiber`
case is inhabited when the permitted value is true and empty when false.
Thus the type interpretation is not just a constant truth token.

`Selected` stores a term and a witness in its reflexive identity fiber.
Its substitution, key and composition laws hold at source level. The semantic
observation is the entire dependent package `(b, refl b)`, and
`Selected.eval_two_substitutions` compares those packages exactly. Native Lean
equality interprets identity here, so identity proofs are proof irrelevant;
this construction makes no claim about higher or proof-relevant identities.

## Frozen client and controls

The context has `x : (ac | Bool)` and `y : (1 | Bool)`, with locks `b;c`.
`κ = alpha tensor id_c` permits `x`. The selected source term returns
`(x^κ, refl(x^κ))`. `exact_native_comparison` proves that its complete observation
is the ordinary Lean function `native x`, which requires only the explicitly
restricted input `x`.

The first substitution renames the permitted variable to a fresh variable
with the same annotation and replaces the ordinary variable by false. The
second negates each variable in the fresh context. Fresh names have the same
de Bruijn indices and annotation shape, so both substitutions use `Γ` as
source and target in Lean. They are distinct substitutions, and the first
changes the ordinary coordinate. For all inputs `(x,y)`, the sequential and
composite substitutions return exactly `native (!x)`. The cases `(true,false)`
and `(false,true)` independently expect false and true, respectively.

The controls distinguish missing permission from an empty result type:

- `Cell.length` rules out both `1 ⇒ bc` (ordinary access) and `1 ⇒ ac`
  (illicit replacement). These are source derivability obstructions, independent
  of a collapsing interpretation.
- `all_terms_independent` covers every generated Boolean term at the locked
  context, and `all_selected_independent` covers the full dependent packages.
  Consequently `ordinary_projection_not_definable` rejects any generated term
  denoting `y` for every valuation, including attempts hidden behind substitution.
- The native route's `ordinary_projection_does_not_factor` rejects factoring
  `y` through `x`, using the same two valuations with fixed false `x`.
- `closedSelected` inhabits the requested result type without variable access.
  Rejection concerns the occurrence of `y`, not all terms of that type.

## Comparison and disposition

| Route | Author supplies | Derived contract |
|---|---|---|
| Native restricted context | A function of the permitted input and its selected reflexivity proof | Exact pair; ordinary projection fails factorization |
| Generated modal fragment | Annotated declarations and a permitted cell for the variable | Access restriction, admissible substitutions, key coherence, exact dependent pair after substitution |

The native client remains the simpler interface for this single observer.
The generated route adds a reusable derivability restriction and substitution
closure that a projection factorization alone does not supply. Neither route
is measured evidence of author productivity; source lines and proof length
were not used as a ranking. The selected observation and equality contract
are identical on both sides. The native route does not incur an artificial
requirement to expose modal annotations.

Adopt this bounded fragment as checked access/substitution evidence under
#289/#36; retain native explicit reasoning. A concrete next obligation, if a
consumer needs it, is annotated dependent context extension where the later
declaration's type depends on an earlier accessible variable, with comprehension
and key/substitution coherence. The present identity families do not establish
that extension. Parallel proof-relevant cells require a separate model choice;
thin reachability cannot assess them. Full cohesive/crisp interpretations,
combined modal/higher models, normalization, elaboration and migration of
ordinary clients remain outside this result. #235 owns compatibility assessment
if these later consumers motivate a shared interface.

A possible shared blind spot is that the selected diagonal identity fiber is
always inhabited and proof irrelevant. The unequal-endpoint fiber control tests
family dependence, but does not test arbitrary dependent telescope assembly or
higher witnesses. That limitation is a reason to retain the next obligation,
not to infer that an access layer automatically solves dependent model building.

## Statement review and validation

The development began from the independently expected permitted pair, negated
pair after the two substitutions, and rejected ordinary projection. The missing
connection was a generated judgment/model interface, not an unprovable native
pair calculation. Focused checks then connected these cases to the public
substitution and interpretation results. Early compile errors concerned Lean
elaboration and heterogeneous lifted proof equality; none justified changing
the expected observations.

Statement review checked every new declaration through the following groups:
word cells preserve length and compose in the stated order; key pullback is
contravariant; substitutions supply terms at declaration words; term equations
quantify over arbitrary generated terms; identity families retain both endpoints;
selected equations compare entire dependent packages; forbidden access uses
uninhabitable cell premises rather than postulated security assumptions.
The concrete valuations establish satisfiable positive inputs and distinguish
both Booleans. Semantic identity interpretation intentionally uses Lean's proof
irrelevance. No source-equality reflection from evaluation is asserted.

The public entrypoint imports the example and its library. Acceptance uses the
README's committed-candidate build, exhaustive proof audit and immediate
candidate-record verification. The orchestration handoff records the candidate
hash and command results; this report does not substitute for those checks.
