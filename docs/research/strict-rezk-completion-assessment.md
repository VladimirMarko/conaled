# Strict Rezk completion and dependent-model coherence

Assessment for [#397](https://github.com/VladimirMarko/conaled/issues/397),
under [#289](https://github.com/VladimirMarko/conaled/issues/289).
**Defer a new completion implementation.** Bocquet addresses a missing
homotopical global-sections construction. This is a different obligation from
making dependent substitution strict or reducing authors' conversion work.
His completion's extension operations are expressly only weakly stable under
substitution, so the construction cannot be advertised as solving all three.

## Exact construction and hypotheses

The source is [Bocquet, 2311.05849v2, sections 2, 4–7](https://arxiv.org/pdf/2311.05849v2).
The HoTT signature is recorded in the
[homotopy-canonicity assessment](homotopy-canonicity-extraction.md#the-theorem-being-considered).
Here `model` means a category with families carrying that signature, with
locally representable term presheaves and structure-preserving model morphisms.
The ambient metatheory is Cartesian cubical presheaves, not native Lean equality.
The category and model laws use strict equality in that metatheory; the
object-language identity types still retain higher structure. This is the
reason for the qualification “strict” in the paper's introduction.

Theorem 5.18 (64 in the HTML rendering) assumes a **global algebraically cofibrant model with fibrant
components**. Fibrant components means fibrancy of each `Tm(Γ,A)`; universes
also give fibrancy of type components. Algebraic cofibrancy supplies chosen
lifts against split trivial fibrations, whose term-lifting condition is exact.
Lemma 5.9 derives democracy. Cofibrancy is not an automatic property of every
concrete semantic model.

Construction 5.10 freely adds `Cof`-extension structure to the families
`Σ y, Tm(Γ, Id_A(x,y))`. Its universal property is initiality among models under
`M` equipped with this selected structure; maps to another such model must
preserve the added operations. Propositions 5.5, 5.15 and 5.17 establish completeness,
fibrant components and an **external** split weak equivalence respectively.
Weak term lifting returns a preimage together with a target identity witness,
not an exact preimage. Completeness makes the displayed singleton contractible
as a cubical fibrant set and identifies object Id terms with ambient cubical
paths. It does not identify those paths with Lean `Eq`.

The externalization is global sections, equivalently evaluation at the terminal
cube. Section 2 needs interval tinyness, weak composition, and cofibrations
generated by interval equalities and finite conjunction/disjunction, including
diagonals. Section 7 leaves generalization to De Morgan cubes and strictly
substitution-stable extension structures open. These limits apply to the
inspected version; the theorem is not a generic completion for any category of
models or any choice of cube category.

## What this preserves and what it does not construct

A structure-preserving map still interprets the specified type formers and
rules. Split weak equivalence adds a way to recover terms up to object
identification after externalization. That is the useful property for
recovering the canonicity witness in #396. It is weaker than literal equality
of selected terms, and does not by itself preserve an evaluator, cost model or
chosen source presentation. A compiler needing one of those observations must
state another comparison and prove it compatible with the completion map.

Nor does completion equip a universe-free model with the univalent hierarchy
needed as input. Treating univalence as an assumed input field would merely
move the missing theorem. Remark 5.19's freely generated closed axioms concern
cofibrancy; it does not extend the initial-model canonicity theorem to arbitrary
inconsistent extra axioms or new equations.

## Applicability test and owned gaps

The local audit is at `78540f8f30ed8cb1afa7dc799a96dac65fec1458`.
Test the candidate input consisting of the existing cubical dependent model.
It has constructed identity/filling operations and selected substitution laws.
The capability matrix in its construction report explicitly omits universes
and univalence. It therefore fails the **HoTT-signature input requirement** of
Theorem 5.18 before any question of cofibrancy arises. No algebraic cofibrancy
proof, full ambient presheaf realization of the paper's `Cof` structure, or
fibrancy of all components of such a full model is constructed in the inspected
modules. The current nontrivial higher identity observation remains useful;
this failure does not invalidate it or show that completing an extended model
is impossible.

There are two possible promotion triggers, with different owners:

- **#36/#396:** an admitted HoTT source needs a strict homotopical global-sections
  functor and an identity-witness return route. First select that source/model,
  construct its universe/type-former package and the ambient cubical assumptions,
  then prove the chosen cofibrancy and component-fibrancy requirements. Retain
  the selected higher observation through the external comparison.
- **#289:** a new model needs strict substitution. Compare direct construction
  and local universes against its actual constructor/eliminator obligations.
  Do not substitute Bocquet's weakly stable extension operations for a missing
  strict-stability theorem. If those operations themselves must be internal to
  the completed model, the unresolved strict-stability construction is a separate
  research obligation.

These are conditions for reopening construction, not an automatic sequence of
implementation issues. Existing direct models and ordinary Lean callers can
continue without either construction. No new general completion framework or
standalone quotient experiment is justified by this consumer. This report
adds no Lean definition or axiom and claims no formalization of the cited papers.
