## What the experiments must distinguish

An algebraic interpretation and an execution contract answer different questions.
A result-preserving compiler may change cost. Extend the observations with optional
contracts where needed and prove compatibility, following the
[counted-stack experiment](counted-stack-contracts.md). None of these tickets
requires every model to implement the same execution interface.

Choose equality and observations from the specification. Retain paths, selected
witnesses or histories where observed; justify any erasure. Ordinary equivalence
transport remains useful without univalence. The latter becomes an obligation
when the retained source reasons through an equivalence as a path between types.
Listing such requirements does not construct their model.

#430 is a bounded adaptation of the systems work, not a whole-book port.
[The existing feedback experiment](approximate-wiring-experiment.md) already
supplies a finite-horizon comparison. The new question is whether an actual
numerical consumer can reuse it while retaining its admission, failure and
observation contracts. Input admission, semantic approximation and resource cost
need separate evidence. FRP progress and stochastic full-law comparison remain
with their existing owners; this adapter does not establish them.

#431 keeps an independent exploration open even without an incumbent client.
It asks for an actual restricted construction, its compatibility hypotheses and
its computational limits. A negative result is useful when it identifies the
failed hypothesis and an explicit disposition. It cannot justify abandoning
other traditions merely because they do not fit current interfaces.

#432 assesses whether older theorems express their intended claims. Lean checks
proofs of the statements supplied to it; a true statement with the wrong scope
can still fail its intended application. Automated lint can help select review
candidates, but cannot certify that correspondence. The audit must publish its
coverage and distinguish paper errors, weak statements and misleading prose.
