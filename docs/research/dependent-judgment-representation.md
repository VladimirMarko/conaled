# Guarded derivations: representation checkpoint

This addendum records the representation decision on 2026-11-05, after the [mathematical freeze](dependent-judgment-freeze.md), commit `0624161`. It does not replace that freeze. The coordinating agent approved investigation of guarded derivations after a checked dependent specialization. The complete interpretation experiment and adoption decision remain outstanding.

The first proposal used compatible sections of a chosen diagram of models. Restriction along a diagram map is useful, but only forgets components. It does not create an interpretation in a new setting. Even a diagram consisting of one Bool carrier with no nonidentity arrows permits either selected element; adding negation as an automorphism permits neither invariant selection. A fixed-model GADT has a related problem: interpreting it along a map from its source model requires a whole model map, rather than merely an assignment to its primitive signature. These observations reject those mechanisms as sufficient accounts of generatedness. They do not reject compatible sections as joint semantics for already interpreted derivations.

The current experiment uses raw operation terms and guarded equational derivations. Contexts, families, terms, substitutions and telescopes are values classified by source predicates. Judgments are indexed by source expressions and hypotheses, with no quantification over the current `Model` in their indices. An actual contextual model supplies an interpretation of the operations and proves the guarded rules. Recursive source interpretation and soundness then reuse one derivation in another supplied model. No initiality or arbitrary-host-function parametricity theorem is assumed.

This follows the essentially algebraic account of dependent structure: operations have specified domains of definition, expressed here by premises. The generalized-algebraic-theory literature provides the external candidate, including its distinction between specified structure and uniform families; its initiality theorem is not imported as a theorem about this Lean development. [Bezem, Coquand, Dybjer and Escardó, §§2–4](https://arxiv.org/pdf/2012.08370)

The host interpreter currently totalizes operations with a distinguished invalid value. Classical equality is used to check metatheoretic context and family indices before transporting a stored semantic value. For well-sorted inputs, the evaluation equations return the exact supplied operation and selected term. This does not introduce classical selection into the source calculus or identify object-language identity with host equality. A semantic map need not reflect sorting: therefore total-algebra homomorphisms on arbitrary invalid operands are only a sufficient comparison, not the intended final map requirement. Preservation on derivably well-sorted recipes must be established separately.

The first checked case is the variable/pair computation rule. `variablePairDerivation` is an annotation-free derivation. `variablePair_valid` proves the rule in every actual `StructuralModel`, using its comprehension laws and the dependent type equation. `interpret_variablePair` consumes the general soundness theorem. The retained example interprets the family `A(n)=Fin(n+1)` along `n↦n+2`, retaining the selected element `n`; observing the result at 3 yields 3 in `Fin 6`. That observation is extracted through source interpretation. It is not a separate arithmetic proof substituting for the source theorem.

At that first checkpoint, the case established that the proposed boundary could express and interpret a genuinely dependent rule without the old universal annotations. It did not establish contextual J, the memo's transport certificate and dependent action, coherent presentation comparison, or the ordinary author's full task. Those remain requirements of #315. The Type instance is a dependency check, not a higher-model interpretation.


The next checked checkpoint constructs the full contextual operation interpreter, including finite dependent telescopes, the reflexive branch map, reindexed branches, and J. `Contextual.model` proves every currently admitted guarded rule from the actual contextual model laws. In particular, `jSchema_inputs` reconstructs the complete dependent motive and branch from the source premises; `jBeta_valid` and `jSub_valid` use the actual J computation and substitution laws. The source authoring interface contains syntax-indexed context, type, term, substitution and telescope derivations. It has no semantic annotation argument.

`Command.fresh` builds a reindexed command's tail, motive and branch using those derivations. `Command.substituted_eq_fresh` constructs its comparison from the J substitution rule, and `Command.substituted_ne_fresh` proves that the two recipes have different outer syntax constructors. `Command.comparison` retains typing of both operands. This is a source-level substituted-versus-fresh discriminator; the specified coherent presentation instance remains separate work. It does not reopen #107.

Statement review at this checkpoint checked the actual quantifiers and premises: the source command has no model parameter; arbitrary finite tail length is retained; branch typing uses the motive pulled back along the full reflexive inclusion; J substitution uses the constructed branch map. `Examples.GuardedContextualJudgments.interpreted_beta` consumes the generated source proof through the universal interpreter at a supplied full model and dependent problem. The earlier finite-family observation remains the concrete dependent value check. No host equality of interpreted endpoints is admitted as object identity evidence in the source.

The partial-map boundary is narrower than arbitrary raw Horn equality. Structural maps commute with defined operation results, without reflecting equality or sorting, and the generic partial-map evaluation theorem then preserves defined expressions. An arbitrary raw equality premise can equate invalid expressions. Such a premise is not automatically transported. Typed comparison contracts must retain definedness of both operands, supplied by their typing derivations; general Horn soundness still accepts separately supplied premises at each model. The remaining contextual map adapter must follow this same boundary.

These are focused, checked construction checkpoints, not an adoption verdict or final candidate validation. The selected memo, both substitutions and dependent certificate action, concrete coherent comparisons, typed premise transport, migration accounting and complete candidate audit remain outstanding.

The next comparison checkpoint completes `ContextualMaps`: a `ModelMap` acts on contexts, families, sections and substitutions, strictly preserving the structural primitives and the chosen contextual J. Pairing preservation is derived from comprehension uniqueness; it is not a field. Telescope transport, root inclusions, tail maps, motives and branches are constructed recursively before the primitive J law is used. `PartialHom.eval` then proves uniformity of every defined expression. `TypedMaps` derives that definedness from source typing and transports the complete assumption list when each equality assumption has typed operands. This is a checked boundary, rather than a promise that arbitrary raw Horn assumptions transport.

The negative controls exercise both sides of that boundary. `GuardedJudgmentBoundaries` interprets the same two family-typing hypotheses in two native valuations. Their decoded families agree in the first valuation, but are Empty and Unit in the second. General soundness refutes a source equality derived from those typing hypotheses alone. The same module constructs a noninjective full model map to a collapsed model. A malformed family substitution is invalid before this map and valid afterward, refuting unconditional evaluation preservation on raw syntax. Valid generated derivations still inherit the partial-map theorem. Loss of information is therefore permitted by the interpretation contract; equality reflection is not inferred.

Specified coherent comparison has a separate concrete construction. `NativeTypeModel` supplies full contextual J by extending along the reflexive-root equivalence, including its substitution law for arbitrary finite telescopes. `CoherentTypePresentations` compares dependent families by fiber equivalences over a context equivalence. It constructs the induced total contexts, dependent term actions, identity-family action and reflexive branches. Unit and composition are proved for family and telescope actions. Its J comparison follows from the commuting root square and the transported branch, without a field assuming the resulting term equality.

`CoherentGuardedJudgments` connects that construction to the generated source. The same `command n` is evaluated at the two constructed assignments. The concrete context is `Nat × Bool`, with Bool flipped; `Fin(n+1)` is presented as `Option(Fin n)`. Two dependent tail families and the motive change as well. The source recipe selects 2 in `Fin 4`; its target interpretation selects the specified code `some 1`. Both evaluations are defined by their source typing. These are unequal family presentations, not merely a change of base applied to an unchanged family. This coherent instance covers Type-family presentations with the specified fiber equivalences; it is not a theorem that arbitrary contextual models are coherently equivalent. Generic strict-map preservation remains available for every supplied contextual model, including the existing groupoid model. Native equality here does not discharge the separate higher-model gate.

Raw operation trees now reuse the existing compositional-coalgebra core. `FinitaryTerm` contains the original leaf/node tree, substitution, fold, and their laws; both `CompositionalCoalgebra.Term` and `GuardedTheory.Term` expose aliases. Source-specific var/app spelling does not introduce another term representation. A focused regression rebuilt the existing coalgebra consumers as well as the guarded examples. Derivation rules, guards and the invalid-value interpreter remain specific to the guarded theory.

These comparison checkpoints have focused Lean builds. They are not the final candidate acceptance. The source memo's value, dependent certificate and dependent action under both substitutions, the final migration decision, and exhaustive candidate validation remain outstanding.

`GuardedCommandComparisons` joins the two comparison mechanisms in the public discriminator. `evaluatedFresh_value` interprets the generated substituted-versus-fresh equality, rather than assuming equality of the two decoded outputs. `fresh_coherent_observation` composes it with the constructed coherent J comparison for any simultaneous substitution and finite tail. Its concrete case uses the nonidentity map `(n,b) ↦ (n+1,b)` and retains the specified code `some 1` after the fresh command is built. `Command.comparison_map` supplies the corresponding strict-map theorem. These results do not resume #107 or choose #108's theorem.

The indexed-setting case now uses the approved #319 construction. `GuardedInternalSetting` authors a nested pairing recipe, both projection recovery derivations and a two-substitution payload equation before choosing a model. Its interpretation assigns the actual families `Fiber P` and `Fiber Q` over `Total P`; the second selected setting depends on the first generic value. The source payload comparison is composed with #319's constructed context, family and dependent-term comparisons. The same source recipes are reused after both reindexings. In the concrete case the payload is 6 at 2; reversing the two base maps distinguishes 2 from 3 at 0. Settings here are supplied mathematical semantics and controlled signature assignments, not newly added object-language setting codes.

`GeneratedContexts` separately constructs a source substitution to empty by recursion on empty and context extension. The two-extension specialization permits the second family to depend on the first variable. Its interpretation inherits partial-map preservation. This recovers existence in the generated fragment, without asserting uniqueness, ambient terminality, or a new primitive operation. The structure audit's unresolved generated-arrow uniqueness question remains unresolved.

The ordinary author supplies expressions for schematic data and source derivations of their context, family, term, substitution and telescope premises. Hypotheses expose dependencies: a family over an extension is a different guard from a family over the original context. The author composes derived source operations and supplies the mathematical branch for J. The author does not provide model-indexed annotations, prove homomorphism laws, reprove J substitution for each interpretation, align decoded branches manually, or recover syntax from an arbitrary Lean function. When reusing a derivation at a new model, the model builder supplies the primitive interpretation and proves its rules; the assignment supplies the declared primitive data and discharges their guards. Strict-map reuse then follows from the constructed map and typing. Coherent reuse in the concrete Type scope supplies fiber equivalences; their context, term and branch actions and the final J comparison are constructed once.

This separates three costs. The source author still proves mathematical typing and identity premises. The model builder establishes semantic operation laws and chosen primitive preservation, including contextual J. Lean's implementation carries dependent parser checks and transports in the semantic builder. Moving those last two costs into the ordinary client's record would fail the experiment's criterion. A fixed template repairs repeated bookkeeping in the old source for the commands it covers, but its semantic indices still mention the whole model family. The guarded derivation instead retains a model-independent recipe, interpretable in arbitrary additional supplied models. Arbitrary compatible sections of a fixed diagram retain only their weaker restriction guarantee; no extraction or extension theorem for them has appeared.

Migration is incremental. Existing `Typed` derivations and their raw erasures remain available, as do the groupoid model and its path-sensitive observations. New source judgments recover structural composition, comprehension, conversion, object Id/reflexivity and full contextual J; the source model interprets those rules in every existing full model. Raw recipe evaluation does not inspect a typing proof, so interpretation is independent of the derivation witnessing the same expression. No initiality theorem or automatic translation of every existing annotated derivation has been established. Retiring the old generated API would require a checked translation or explicit replacement of its clients, including named derived commands and their exact selected observations. Neither native Type examples nor source-only higher evidence permits retiring the higher-model gate. Object Sigma is still a separate #317 extension, not a synonym for the contextual package used here.

Source interpretation is evaluation of a retained finite operation tree. Inspectable source is already present in a generated derivation's indices; it is not extracted from semantic values. The experiment does not invert semantic interpretation, promise a semantic-to-source round trip, or reify arbitrary host functions. The memo client requires interpretation with selected data preserved, not either extraction round trip. Both lossy interpretations and multiple derivations of one raw recipe fit that contract.

The chosen source concatenation eliminates the right path. The existing semantic concatenation eliminates the left path. Their groupoid comparison is constructed using the discrete identity fibers; it is not definitional equality of recipes and cannot identify selected higher certificates in an untruncated model. The new certificate is retained as its own J recipe with reflexive branch, as required by the external memo. Generic source interpretation and strict-map preservation concern that chosen recipe. Any migration equating it with an older selected certificate must supply the appropriate comparison; groupoid proof uniqueness cannot discharge a higher comparison.

The target adapter still consumes the existing full contextual `Model`. Its legacy base/fiber signature fields remain on that semantic interface, although the new source operations and strict-map laws do not refer to them: schematic signatures are supplied through guarded assignments. Removing those legacy fields or constructing a classifying model is not claimed here. The source judgment indices and derivation objects already avoid quantification over that interface.
