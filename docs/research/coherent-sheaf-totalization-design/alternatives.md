# Alternatives and generality assessment for #708

Date: 2026-11-27. Project `f96e378241012feae903d6e06211c26bfe0f94b3`; Mathlib `56a005855ea17e0b0958f73ec801ae140b0a1679`; Lean version supplied by the brief: `v4.35.0`.

## Recommendation

Proceed with a bounded coherent-sheaf totalization, deriving its coherence by transport along the existing fibre equivalences and using Mathlib's CoGrothendieck construction. Preserve the fibrewise API and direct sheaf entry point. The smallest useful shared construction is transport of a contravariant category-valued pseudofunctor along a specified family of equivalences, with a coherent decoder/inverse and vertical recovery. It need not be a universal framework for descent, displays or type theory.

This recommendation is mathematical and architectural, not a claim of measured author savings. The added capability is to compose actual substitution arrows and arbitrary code maps in one category, use generic cartesian factorization and total-map results, and transport constructions over a base through recovery. A currently blocked client is not required to justify that capability. The additional interface should earn its cost through a compositional theorem as well as the Boolean separating case below.

The strongest evidence for retaining the proposal is that its ingredients already match. `CoherentSheafOver.reindex` is precisely equivalence-conjugated sheaf substitution; its comparison isomorphisms and decoder compatibility are proved. Mathlib supplies the sheaf pseudofunctor, total categories and their fibration structure; `CoGrothendieckMap` supplies modification transport and cartesian preservation. The project already uses those latter results in a different, strict-precomposition family. There is no need to rebuild any of those constructions or add new sheaf hypotheses merely to totalize.

## Alternatives

| Route | Mathematics retained or added | Cost and disposition |
| --- | --- | --- |
| Direct sheaf total only | `CoGrothendieck (J.pseudofunctorOver (Type w))` already supplies arbitrary substitution arrows and cartesian lifts. It needs no dense represented-site equivalence. | Keep as the baseline and a public entry point. A code author must decode first and cannot cite a single coherent total recovery theorem until the bridge exists. It is sufficient for callers already presenting sheaves, but does not answer the code-side interoperability question. |
| Transport the pseudofunctor through fibre equivalences | Keeps the independent code fibres and current conjugated reindexing. Derives shared coherence and provides strong maps/modifications for totalization. | Preferred. Keep the helper restricted to categories indexed by an ordinary base unless an actual second need warrants bicategory generality. Instantiate sheaves separately so density/locality/limits stay with their mathematical owner. |
| A smaller induced total category | Objects are `(Γ,A : CodeΓ)`; define its hom from `x` to `y` to be the hom in the sheaf total from the decoded `x` to decoded `y`. Identity and composition are inherited. Fibrewise essential surjectivity gives a total equivalence. | A viable fallback if the near-term deliverable is only a total equivalence. It keeps code objects, but its arrows are presented through decoded sheaves. Recovering the native `A → Rσ B` description requires a hom equivalence using full faithfulness and the counit. Explicit native composition, reindexing compatibility and cartesian recovery still need proof. It shifts obligations rather than proving them unnecessary. |
| Direct displayed-category/fibration interface | Put `LocalCode Γ` over each Γ and native arrows over σ directly; derive a total category and chosen cartesian lifts. This exposes base control without equations on total objects. | A mathematically legitimate competitor. With the current transported reindexing it still needs the same associativity/unit facts. It becomes attractive if subsequent constructions assemble several dependent layers or require native displayed access. No measured implementation advantage has been established here. |
| Sheaf display maps and codomain fibration | Use all commuting squares between displays and pullback squares as cartesian arrows; compare with sheaf-over fibres. | Valuable specialized geometric presentation. `codeDisplayClassification` currently requires subcanonicity and specializes values to `Type b`, the ambient hom universe. It cannot replace general substitution without narrowing that contract. Cross-context compatibility of the fibre comparisons is still needed. |
| Split replacement/local universes | Changes presentation to make reindexing strictly functorial and can support strictly stable logical operations under further hypotheses. | Reserve for a requirement for strict syntax/type-former semantics. A coherent total equivalence needs no such strictness. Do not change the present code fibres or selected substitutions merely to obtain strict equalities. |

The induced-total alternative is a paper-level construction based on a category induced along the object decoder, not a claimed implementation in this checkout. Its fully faithful decoder is built into the hom definition; the substantive obligations are essential surjectivity over each fixed base and comparison with the original code maps. That distinction prevents it from being advertised as independent recovery merely because a total equivalence is easy to package.

A second possible smaller endpoint is to package the code pseudofunctor and strong decoder first, deriving cartesian preservation from `CoGrothendieckMap.map_cartesian` without yet packaging an inverse. That is useful one-way capability, but it is not the stated full recovery endpoint. Given existing fibre equivalences, retaining the inverse/recovery endpoint is justified unless an implementation experiment exposes disproportionate cost.

## External mathematical comparisons

All following sources were accessed on 2026-11-27. They orient the alternatives; no external theorem is treated as a Lean proof.

The Stacks Project, [Section 4.33](https://stacks.math.columbia.edu/tag/02XJ), especially Lemmas 4.33.7–8 and Definition 4.33.9, starts from a fibration with chosen pullbacks to obtain a pseudofunctor. An equivalence of categories **over the same base**, with both functors and the unit/counit over that base, preserves strongly cartesian arrows. This supports deriving cartesian compatibility from a genuine equivalence over the base; an arbitrary equivalence of underlying categories is insufficient. Its 2-morphisms are vertical natural transformations. These facts support both the proposed total bridge and the induced-total fallback, once their base equations are proved.

Ahrens and Lumsdaine, [Displayed Categories](https://arxiv.org/html/1705.04296), Definitions 5.1–5.3 and Propositions 5.4–5.5, distinguish chosen cartesian lifts from mere existence. Their displayed cartesian condition agrees with the projection functor's condition. For the displayed category of slices of any category C, a displayed arrow is cartesian exactly when its square is a pullback; existence of all pullbacks supplies a weak fibration, chosen pullbacks supply a cloven one. This is a genuine alternative foundation, not a deficient pseudofunctor wrapper. The work is formalized in Coq/UniMath and its univalence results are not imported assumptions for Lean. The inspected general definitions do not justify promising definitional equality of this project's recovery or chosen pullbacks.

Lumsdaine and Warren, [The local universes model](https://arxiv.org/pdf/1411.1736), Definition 3.1.1, replace a type over Γ by `(V,E,Γ → V)` and retain arrows between their interpreted types over base maps. Definition 3.1.3 specifies condition (LF): finite products, and dependent exponentials for a display map followed in its domain by a display map or product projection. Section 3.4 then lifts the respective weakly stable logical structures to strictly stable ones. This is relevant to eventual language semantics, but those logical hypotheses and the changed presentation are unnecessary for ordinary coherent totalization. Distinguish the split replacement itself from the stronger hypotheses for lifting logical structure; (LF) is not asserted necessary for every fibration total.

[nLab's Grothendieck construction page](https://ncatlab.org/nlab/show/Grothendieck+construction) and [indexed category page](https://ncatlab.org/nlab/show/indexed+category) supplied search-index orientation toward the pseudofunctor/fibration and displayed-category viewpoints. Direct opening of the Grothendieck page failed with unsupported `application/xhtml+xml`; I did not inspect a complete fetched nLab page. No detailed technical conclusion rests on those snippets. The primary sources above and the pinned Lean definitions carry the comparison.

## Concerns and discriminating evidence

1. **Derivable structure could become recurring caller burden.** This is a design risk, not an existing defect. A constructor demanding separately supplied code associativity, decoder coherence and inverse modifications would expose consequences of the same equivalences repeatedly. Derive them in a bounded helper or the concrete module first. Do not make #723's broader extraction a prerequisite; #708 can provide the exact small theorem and hand reusable evidence to #723.
2. **Universe alignment may dominate Lean work.** The code fibres depend on represented-site and ambient-site universes; the sheaf total need not have identical inferred Cat maxima without adjustment. Preserve independent parameters and test a genuinely unequal site/value-universe specialization. A larger common Cat universe is an encoding choice to account for, not evidence that the underlying mathematics needs equal universes. No elaborated new signature was checked here.
3. **Display comparison can silently strengthen the generic contract.** `CoherentSheafOver.lean:323–336` requires `[J.Subcanonical]` and uses `Type b`; the general substitution section does not. The implementation must keep these entry points separate. `Examples/CoherentSheafOver.lean:135–147` already gives locally invertible restrictions with a globally noninvertible support map in the inappropriate locality setting. Subcanonicity alone must not be substituted for the actual density hypothesis.
4. **All-map recovery can be weakened by convenient examples.** The existing `collapse_not_iso` and `code_collapse_not_iso` at `Examples/CoherentSheafOver.lean:168–184` provide a separating map. An implementation restricted to the cores of the fibres would fail the intended contract even if it recovered every object.
5. **Chosen and adjusted units can differ.** Existing family totalization retains original recovery separately and proves base equations for the packaged `Equivalence.mk` unit. Follow that discipline; do not assert equality of adjusted and original recovery or equality of chosen cleavages without proof.

For the proposed Boolean case, prove through the public total functors that the composites of `p : Bool×Bool → Bool` and `d : Bool → Bool×Bool` project respectively to the identity on Bool and to `(x,y) ↦ (x,x)` on pairs. The latter sends `(true,false)` to `(true,true)`. Include the existing noninvertible collapse as a vertical arrow and use it in a composed substitution arrow; verify total recovery naturality on that arrow. Check preservation of arbitrary cartesian arrows using the public theorem, not only the canonical lift constructor. This case distinguishes base order and retention of noninvertible maps. It cannot prove pentagon coherence, universe generality, or a reusable author capability by itself.

Add an abstract compositional application: an equivalence of these totals over D should induce an equivalence between categories of cartesian sections over any diagram `u : A ⥤ D`, retaining arbitrary vertical natural transformations between sections. On paper, compose a section with the total decoder/inverse, use strict projection equations for the section boundary, cartesian preservation for its arrows, and whisker vertical recovery to obtain the unit/counit. This uses the bridge to transport a whole compatible family of objects and maps. It does not assert effective descent or stackification. If no convenient section API exists, a smaller first application is the same construction for a specified diagram category A with explicit functors and vertical transformations, avoiding a new general sections framework. That is a proposed checked application, not an already validated result or a requirement to finish broader descent theory.

Implementation evidence should compare the direct sheaf route and code route for this application, recording initial adapter obligations separately from reusable proof. It should retain current fibrewise clients, discharge actual instance hypotheses, check native hom/identity/composition comparison, unit/counit verticality, noninvertible maps, cartesian preservation and independent universes. Full build/audit belongs to a later authorized implementation; none was run for this assessment.

## Decision boundary

Prefer transported pseudofunctor coherence plus existing totals. Keep the direct sheaf total and fibrewise APIs. The induced-total route is the smallest credible fallback, with its native-arrow comparison costs explicit. Displayed categories and local universes remain meaningful alternatives for different author constructions; their absent local adapters are not arguments against their mathematics. The evidence does not support mandatory migration, a general productivity claim, arbitrary-input stackification, new type-former closure, or completion of #708. This report recommends a bounded next implementation contract for root's synthesis and acceptance decision.
