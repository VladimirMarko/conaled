## Chosen next boundary

First finish the actual ordinary-input/native-halt proof. Then introduce a reusable raw Boolean decider witness with one fixed finite work alphabet, one fixed finite control type, explicitly supplied blank/start, an injective two-letter nonblank input map, an actual native TM0 transition, a fixed Nat polynomial and a universally quantified EvalsToInTime witness to a stopped configuration with the correct fixed output letter. The machine and polynomial precede the input quantifier. Preserve the stronger full singleton tape and native eval theorem for the concrete controller.

Use no uninterpreted polynomial-time premise. Keep the independent BinaryYes language, literal threshold bits, fixed existing pair protocol and actual small-witness correspondence. A generic complexity owner must not import the rotation application, and no arbitrary whole-word encoder is accepted on the strength of injectivity/length alone. The initial raw-decider owner can remain independent while a later exact codec ownership refactor is considered under an explicit scope change.

## Fixed expectations before a new compiler attempt

- Defaults are the supplied blank and start, including a nondefault true initial source register.
- Input is a per-letter map; [] and [false] are distinct. Neither bit letter is blank.
- All raw words have actual bounded native runs, including malformed framing.
- The endpoint is live and stopped, with the output bit observed there. Outer-none costs one extra step.
- Concrete output is the full ordinary singleton tape and native eval result.
- Certificate witnesses use the existing independently defined language; no per-input machine or free computation hidden in an encoder.
- Pair-time bounds quantify over arbitrary certificates; small-certificate composition is a separate corollary.
- No classical NP or textbook qualification change until the selected remaining correspondence, source integration and validation/review obligations are met.
