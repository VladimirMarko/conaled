# Research recovery and replay

Read `RESEARCH_INDEX.json` and `USEFUL_RESIDUALS.md`. The index records the original
workspace identities and exact hashes of canonical unfinished mathematics, fixed
specifications, actual successful checks and attributed reading. Resolve every
selected identity through `RESEARCH_PATH_MAP.json`; these are packet-relative
paths, not a requirement to recreate the old workspace directory structure.

The three recipes under `reassembly/` reconstruct the exact successful combined
development inputs from current source owners, canonical research bodies and
otherwise unowned glue/query bytes. From the packet root, run:

```sh
python3 current/research/reassemble_research.py current/research/reassembly/generic-ordinary.json --root . --path-map current/research/RESEARCH_PATH_MAP.json
python3 current/research/reassemble_research.py current/research/reassembly/conventional.json --root . --path-map current/research/RESEARCH_PATH_MAP.json
python3 current/research/reassemble_research.py current/research/reassembly/delimiter.json --root . --path-map current/research/RESEARCH_PATH_MAP.json
```

These commands verify the exact target bytes in memory. To materialize an input,
add `--output` with a fresh file outside the packet. This is byte reconstruction,
not compilation, ordinary-module validation or acceptance. Historical full
combined copies and earlier repair variants are intentionally retired; failures
and binding/reading limits remain in the outcomes ledger and current reports.

exclusive-output behavior must not overwrite selected evidence. Timestamp fields
