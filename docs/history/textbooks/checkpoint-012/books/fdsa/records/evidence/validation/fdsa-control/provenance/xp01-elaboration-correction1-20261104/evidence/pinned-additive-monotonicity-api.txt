92: /-- Given an action `μ` of a Type `M` on a Type `N` and a relation `r` on `N`, informally, the
93: `CovariantClass` says that "the action `μ` preserves the relation `r`."
94: 
95: More precisely, the `CovariantClass` is a class taking two Types `M N`, together with an "action"
96: `μ : M → N → N` and a relation `r : N → N → Prop`.  Its unique field `elim` is the assertion that
97: for all `m ∈ M` and all elements `n₁, n₂ ∈ N`, if the relation `r` holds for the pair
98: `(n₁, n₂)`, then, the relation `r` also holds for the pair `(μ m n₁, μ m n₂)`,
99: obtained from `(n₁, n₂)` by acting upon it by `m`.
100: 
101: If `m : M` and `h : r n₁ n₂`, then `CovariantClass.elim m h : r (μ m n₁) (μ m n₂)`.
102: -/
103: class CovariantClass : Prop where
104:   /-- For all `m ∈ M` and all elements `n₁, n₂ ∈ N`, if the relation `r` holds for the pair
105:   `(n₁, n₂)`, then, the relation `r` also holds for the pair `(μ m n₁, μ m n₂)` -/
106:   protected elim : Covariant M N μ r
107: 
108: /-- Given an action `μ` of a Type `M` on a Type `N` and a relation `r` on `N`, informally, the
109: `ContravariantClass` says that "if the result of the action `μ` on a pair satisfies the
110: relation `r`, then the initial pair satisfied the relation `r`."
111: 
112: More precisely, the `ContravariantClass` is a class taking two Types `M N`, together with an
113: "action" `μ : M → N → N` and a relation `r : N → N → Prop`.  Its unique field `elim` is the
114: assertion that for all `m ∈ M` and all elements `n₁, n₂ ∈ N`, if the relation `r` holds for the
115: pair `(μ m n₁, μ m n₂)` obtained from `(n₁, n₂)` by acting upon it by `m`, then, the relation
116: `r` also holds for the pair `(n₁, n₂)`.
117: 
118: If `m : M` and `h : r (μ m n₁) (μ m n₂)`, then `ContravariantClass.elim m h : r n₁ n₂`.
119: -/
120: class ContravariantClass : Prop where
121:   /-- For all `m ∈ M` and all elements `n₁, n₂ ∈ N`, if the relation `r` holds for the
122:   pair `(μ m n₁, μ m n₂)` obtained from `(n₁, n₂)` by acting upon it by `m`, then, the relation
123:   `r` also holds for the pair `(n₁, n₂)`. -/
124:   protected elim : Contravariant M N μ r

126: /-- Typeclass for monotonicity of multiplication on the left,
127: namely `b₁ ≤ b₂ → a * b₁ ≤ a * b₂`.
128: 
129: You should usually not use this very granular typeclass directly, but rather a typeclass like
130: `IsOrderedMonoid`. -/
131: abbrev MulLeftMono [Mul M] [LE M] : Prop :=
132:   CovariantClass M M (· * ·) (· ≤ ·)
