## 1. Precisely which mean is being solved

Write `T` for the measured Exercise 2.4 observation. Its actual checked
source equation is `Resources.QuickSort.exerciseCost_cons`: on a nonempty
list of length `n`, it charges both recursive children and `4*n - 1`, or
equivalently `4*m + 3` when the tail length is `m` and `n = m + 1`. The
two full filter executions and their unit callback costs produce this toll.
`exerciseCost_nil` is 1, and `exerciseCost_singleton` is 5. Append traversal
is a separate observation.

Here `A n` denotes a **real mean of T**, not the deterministic file's
append-cost coordinate. The numerical theorem will use a real sequence
`A : Nat → Real`, with explicit natural indexing and real arithmetic. Its
only mathematical assumptions are the base value and an already-proved
positive-size recurrence:

\[
A_0=1,\qquad
A_n=\frac{2}{n}\sum_{k=0}^{n-1} A_k+4n-1\quad(n>0).
\]

This is a conditional numerical theorem, not a license to assume a recurrence
of either execution. Root and the probability authors must independently
connect each actual mean to this recurrence. Distinct-key hypotheses,
finite probability spaces, pivot-rank uniformity, recursive marginal laws,
and integrability belong to those execution bridges. None is silently
supplied by the arithmetic lemma.

The mathematically exact schematic Lean contract is:

```lean
(A : Nat → Real)
(hzero : A 0 = 1)
(hstep : ∀ n : Nat, 0 < n →
  A n = (2 / (n : Real)) * (∑ k ∈ Finset.range n, A k)
    + 4 * (n : Real) - 1)
```

The notation above is a proposed contract, not checked new source. No
monotonicity or positivity premise is needed: nonnegativity follows from
this recurrence and base. There is no payload carrier, equality instance,
global `Fintype`, order structure, probability law, or sorting implementation
in this numerical interface.

## 2. Deriving the recurrence difference without a zero division

Put `S n = ∑ k ∈ Finset.range n, A k`. For positive `n`, multiply the
recurrence by the nonzero real cast of `n`:

\[
nA_n=2S_n+4n^2-n.\tag{1}
\]

The same **scaled identity** is true at zero by the empty sum: both sides
are zero. This is a tautology, not the positive-size averaging equation at
zero; it contributes no information about `A 0`. The independent base
`A 0 = 1` remains necessary.

Using `S (m+1) = S m + A m`, subtract (1) at `m` from (1) at `m+1`:

\[
(m+1)A_{m+1}=(m+2)A_m+8m+3\qquad(m\ge0).\tag{2}
\]

This successor form is the preferred Lean-facing identity. Every divisor
used afterward is the positive real cast of a successor, and no natural
subtraction has to cross a coercion. It is exactly the requested source
form after writing `n = m+1`:

\[
nA_n=(n+1)A_{n-1}+8n-5\qquad(n\ge1).\tag{3}
\]

For `n=1`, the base gives `A 1 = 2*A 0 + 3 = 5`; this does not apply a
positive-size recurrence at zero. A proof may handle this boundary directly
or use (1)'s explicitly trivial zero case.

Pinned finite-sum support is `Finset.sum_range_succ`. It is generated by
`@[to_additive]` from `Finset.prod_range_succ` in
`Mathlib/Algebra/BigOperators/Group/Finset/Basic.lean`. After normalizing
natural casts and clearing only proved nonzero denominators, (1)–(3)
require polynomial arithmetic. There is no recurrence-solving axiom or
unverified symbolic-algebra dependency.

## 3. Closed form and a compact proof organization

Let `H n = (harmonic n : Real)`, reusing Mathlib's existing global
`harmonic : Nat → Rat`. Define the proposed numerical expression

\[
C_n=8(n+1)H_n-12n+1.\tag{4}
\]

The exact expression uses real subtraction, not truncated natural
subtraction. Its mathematical derivation is visible by dividing (3) by
`n(n+1)` and putting `B n = A n / (n+1)`:

\[
B_n-B_{n-1}
=\frac{8n-5}{n(n+1)}
=-\frac5n+\frac{13}{n+1}.
\]

Since `B 0 = 1`, summing from 1 through `n` gives

\[
\begin{aligned}
B_n
 &=1-5H_n+13(H_{n+1}-1)\\
 &=8H_n-12+\frac{13}{n+1},\\
A_n
 &=8(n+1)H_n-12n+1.
\end{aligned}
\]

This explains the constants 8, 12, and 1. The recommended Lean proof is
shorter than formalizing the telescoping calculation as a new reusable
library:

1. Reuse `harmonic_zero` and `harmonic_succ`, with rational-to-real casts,
   to prove `C 0 = 1` and the successor identity (2) for `C`.
2. Prove the scaled prefix identity (1) for `C` by natural induction,
   `Finset.sum_range_succ`, and the successor identity. The zero case is
   an empty-sum tautology. Divide only for `0 < n` to obtain the required
   recurrence for the closed expression.
3. For an arbitrary numerical sequence satisfying the stated base and
   recurrence, derive its successor identity as in §2. Induct on `n`,
   cancel the nonzero factor `n+1`, and obtain `A n = C n`. No stronger
   assumptions are needed.

Step 2 is useful even when a probability client does not define one actual
mean sequence for all sizes. The average-input client can induct directly
on a fixed finite subset's cardinality, substitute the closed expressions
for its actual child means, and finish with the proved recurrence of `C`.
This avoids pretending that a fixed finite environment contains subsets
of every natural cardinality.

An actual size-indexed mean can instead apply the generic uniqueness result
from step 3. Both presentations use the same closed expression and share
the same bound proofs. No second harmonic definition or sorting/resource
carrier is needed.

## 4. Nonnegativity and explicit logarithmic bounds

### 4.1 Norms require a lower bound too

Prove `0 ≤ C n` for every natural `n` by induction from `C 0 = 1` and
(2). Its right-hand side is nonnegative when `C m` is nonnegative, and
`m+1 > 0`. The same property transfers to any `A` proved equal to `C`.
This matters because Mathlib's Big-O compares norms. Merely proving a
one-sided real upper bound would not control the absolute value of an
arbitrary real sequence.

### 4.2 A natural-logarithm bound for every positive size

The pinned theorem `harmonic_le_one_add_log n` states, with real coercions,

\[
H_n\le1+\ln n.
\]

It is valid even at `n=0` under Mathlib's totalized logarithm, but the
following cost bound uses `n≥1`. On this domain `ln n≥0`, `n+1≤2n`, and
`-12n+1≤0`. Consequently

\[
\begin{aligned}
0\le C_n
&\le8(n+1)(1+\ln n)-12n+1\\
&\le8(n+1)(1+\ln n)\\
&\le16n(1+\ln n).\tag{5}
\end{aligned}
\]

Use `Real.log_nonneg` for `1≤n` and explicit nonnegative factors when
multiplying inequalities. The positivity of the casts follows from the
natural-domain hypothesis.

### 4.3 A genuine `O(n ln n)` theorem

For `n≥2`, let `L = Real.log 2`. The pinned APIs give `0<L` and
`L≤Real.log n`. Therefore

\[
1+\ln n\le\left(1+\frac1L\right)\ln n,
\qquad
0\le C_n\le16\left(1+\frac1{\ln2}\right)n\ln n.\tag{6}
\]

The desired theorem is the standard filter statement

```lean
Asymptotics.IsBigO Filter.atTop
  C (fun n : Nat => (n : Real) * Real.log (n : Real))
```

Use `Asymptotics.isBigO_iff.mpr`, choose the displayed positive real
constant, and use `Filter.eventually_atTop.mpr` with the natural threshold
2. Rewrite both norms with `Real.norm_eq_abs` and `abs_of_nonneg`, using
the all-size nonnegativity of `C` and the nonnegativity of `n * log n`
on the eventual domain. The lambda's argument must remain explicitly
`Nat`; an accidentally inferred real index would change the theorem.

### 4.4 The book's binary logarithm, with a concrete constant

Mathlib defines `Real.logb b x = Real.log x / Real.log b`. For base 2,
`0<ln 2` justifies the exact change-of-base identity

\[
\ln n=(\ln2)\log_2n.
\]

For `n≥2`, `Real.logb_self_eq_one` and
`Real.logb_le_logb_of_le` give `1≤log₂n`.
`Real.log_le_sub_one_of_pos` at 2 gives `ln2≤1`. Hence

\[
1+\ln n\le2\log_2n,
\qquad
0\le C_n\le32n\log_2n\quad(n\ge2).\tag{7}
\]

This gives a second genuine `Asymptotics.IsBigO Filter.atTop` statement
with right-hand side `fun n : Nat => (n : Real) * Real.logb 2 n`, constant
32, and threshold 2. It does not confuse `Nat.clog 2 n` with the real
binary logarithm. An alternative exact constant obtained directly from
(6) is `16*(1+ln 2)`; the rational constant 32 is adequate and simpler.
There is no need to generalize to arbitrary logarithm bases for this
bounded source obligation.

### 4.5 Zero and one are intentional exceptions to the `n log n` inequality

`C 0 = 1`, `C 1 = 5`, and both `n*log n` and `n*logb 2 n` vanish at
`n=0` and `n=1`. Therefore no finite constant proves the proposed scalar
`n log n` bound at those inputs. The positive-size bound (5) excludes zero;
the bounds (6) and (7) and their Big-O proofs use threshold 2. These
exceptions are compatible with the asymptotic claim and must not be
removed by changing the empty or singleton tariff.

The agreed actual recurrence interfaces are `sizeMean_zero` and
`sizeMean_succ`, with the successor form

\[
\operatorname{sizeMean}(m+1)
=\frac2{m+1}\sum_{r:\mathrm{Fin}(m+1)}
  \operatorname{sizeMean}(r.\mathrm{val})+4m+3.
\]

`Fin.sum_univ_eq_sum_range` converts the finite-type sum to the prefix
form used here. A real cast of the natural toll `4*m+3` equals
`4*((m+1 : Nat) : Real)-1`; all cancellation uses positivity of the
successor. The random-pivot author also plans a positive-size range-sum
wrapper matching §1 exactly. Only after these actual theorems are proved
may the generic numerical solver be instantiated with `sizeMean`.
