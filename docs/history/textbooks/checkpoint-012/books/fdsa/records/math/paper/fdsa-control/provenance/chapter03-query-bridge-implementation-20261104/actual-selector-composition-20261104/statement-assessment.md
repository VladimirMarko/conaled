## Domains and nonvacuity

Generic acquisition/measured laws require only the checked worker's LinearOrder payload structure and an actual Fin n input; no Inhabited payload, finite payload, injectivity or Nodup premise is imposed there. Every natural rank is allowed, including invalid ranks and n=0. ObservedSelect_run/total construct the runs used by later conditional claims. Empty observations are none with cost2, not a fabricated payload.

Valid semantic correctness specializes to Int and k:Fin n, hence k.val<n and n>0. The fixed default0 is proved irrelevant by an actual some result before Selects is established. Selects covers all integer inputs including duplicates. Nodup(ofFn input) is confined to the competitor lower-bound/comparison domain, as in the original C03-081--083 contract. The private adapter proves injectivity instead of assuming it. Totality of competitors is used to construct real comparison witnesses; the earlier pairMinimum and actual selectedValue supply nonvacuous examples of the class.

Tariff c is any Nat in exact/upper laws; c>=1 is explicit in input-size lower bounds and optimality. Uniform A/B/C/K are bound before payload type (where applicable), input, rank, traces and observations; competitor K also precedes c. The final paid cost includes actual selectRun source calls. Neither a free deterministic computation, arbitrary resource with assumed coverage, nor a target linear-bound hypothesis is used. Frontend bookkeeping/plan lookup/projections retain the stated zero tariff of the coordinate model; no runtime/randomized/free-bulk-model lower bound is claimed.
