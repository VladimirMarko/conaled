## Mathematical assessment of the five stages

1. **Actual observations and source recurrence.** `observedCost` is exactly the real
   cast of the existing exercise-cost coordinate on the original sample's selected
   order. Both children erase the actual head occurrence, then use true/false outcomes
   of the source comparator. On the optional-head event, actual tail filters are
   proved equal to same-permutation child projections. The source cons theorem then
   gives the natural toll `4*(card-1)+3`; no expected recurrence is assumed.

2. **Conditional law and integrability.** Completeness supplies a finite label
   enumeration locally. Original and conditioned actual observations are integrable
   on the finite permutation space. A member pivot gives positive finite head mass;
   its conditional probability instance is established before integrating constants.
   Each fixed child lies inside the selected remainder. Public conditional and
   original HasLaw records have a common target uniform order measure, so their
   integral transports agree. There is no assertion of independent children, a fresh
   tail, or an unchanged whole conditioned environment.

3. **Original integral recovery.** Distinct optional heads are disjoint, and nonempty
   selected order has a head in S. The finite measurable head partition covers the
   original sample space. The restricted/conditional integral scaling uses the actual
   reciprocal-cardinality mass and cancels only after proving a nonzero real cardinal.
   Empty S is separate and has mean1. The resulting generic actual recurrence still
   accepts arbitrary Boolean comparators.

4. **Key rank and fixed-environment induction.** The explicit hypothesis is InjOn of
   the key map only on S. The finite key image is ordered using the existing Mathlib
   order isomorphism; label I receives no order/default. A selected-label/key-image
   bijection yields a rank equivalence, and the actual lower child key image is the
   image of Iio k. Its card is k; the complement card is n-1-k. The two rank sums are
   reindexed/reflected. Strong induction quantifies every actual smaller subset of
   the same environment with inherited local key injectivity. Only then is the proved
   numerical closed-expression recurrence used. No fictional actual sequence over
   all sizes in a fixed finite label universe is introduced.

5. **Actual payloads and growing families.** Occurrence labels are Fin(length xs),
   with canonical positions and lookup into xs. Mapping preserves the entire list
   permutation, length, and the existing execution observation. No payload equality,
   order, measurability, finiteness or default instance is required. The explicit
   distinctness premise is `(xs.map key).Nodup`, which makes the occurrence key map
   injective. The actual input mean equals closedForm(length xs). Positive-size
   natural-log bounds and binary-log bounds for n≥2 follow. For Big-O the family
   contains actual lists of length n, so its occurrence sample environment varies
   with n. The optional literal-cost mean uses those same samples and proves the
   inequality exercise≤literal≤2*exercise before the constant64 logarithmic bound;
   it does not assert the exercise harmonic identity for append-inclusive work.
