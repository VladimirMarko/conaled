# Current paper mathematics and uncompiled work

This is the canonical place for new useful paper progress outside committed code.
Use one `progress.md` for the current bounded problem: precise claim and assumptions,
proof/counterexample or attempted route, source references, unresolved obligations,
and the next mathematical action. Label paper-only and uncompiled results honestly.
Retain meaningful alternatives rather than replacing a harder claim silently.

If execution is blocked after the RESUME setup budget, make useful mathematics
here instead of prolonging environment diagnosis. Explicit Lean scratch files may
be kept in `drafts/`; their presence supplies no compilation or acceptance credit.
Preserve them before capture and do not reset/drop source to satisfy a clean gate.

Do not add runtime binaries, caches, partial downloads, nested checkpoints, full
repository copies, repeated inventories or large uncurated setup transcripts.
Do not rewrite frozen `records/`. Update STATE with the current bounded scope and
evidence, then follow DURABILITY/CHECKPOINTS before another extended phase.
