# Prospective interface boundary

This snapshot precedes held-out task selection. It freezes the reviewed source
interfaces at `7b8c00ae171c8a0b6de696e42aaf8470ff1e7c96`. The adjacent JSON records
all transitive local imports and their SHA256 hashes. No task-specific support
is added. Task statements, calibration, references and author instructions will
be frozen separately after approval of this boundary and before dispatch.

The retained baseline is `PathTransport.Typed.Authoring`, including its existing
`PathCommand.rebuild` repair and public worked callers. Its source derivations
carry `CtxCode`, `TyCode`, `TmCode` and telescope annotations indexed by all
`PathTransport.Typed.Model`s. Those are presentation obligations alongside raw
source typing; the experiment must not pretend the baseline has no command API.

The candidate is `DependentJudgments.Contextual` through `Templates`, plus the
actual `Sigma.Authoring` extension. Source guards mention expressions and
judgments. Their generic soundness interpreter supplies semantic validity in a
chosen full contextual model. Ordinary source authors supply neither semantic
operation laws nor all-model annotation equalities. The candidate import closure
contains the shared semantic model used by both arms, but no baseline author
module. The baseline closure contains the common Sigma semantic capability, but
no guarded candidate author module. These shared dependencies are disclosed
common mathematical support, not secret access to the other author's work.

The matched model class is every full contextual `PathTransport.Typed.Model`
equipped with `Sigma.Stable` on its structural reduct. The stable capability is
the selected #317 comprehension isomorphism, with both inverse laws and stable
family/pack operations. It includes judgmental eta. Neither a beta-only model
class nor an arbitrary higher model is claimed. This additional capability is
used to assess reuse after extension, not assumed to exist for every old model.

The comparator uses exact reduct reuse because the retained Typed source has no
object-language Sigma. Both authors must retain the same dependent Id/J argument
and its chosen witness under repeated simultaneous substitution, with explicit
source typing and type alignment. Both must establish exact selected-data reuse
in models carrying the actual admitted extension. The candidate embeds the
source derivation into `Sigma.theory` and uses its exact reduct; the baseline
interprets its unchanged derivation in the same full model's reduct. This tests
reuse of the old argument. It does not compare the effort of authoring a new
Sigma term. The constructor's formation, introduction, dependent elimination,
computation and selected eta are separately checked #317 capabilities, and must
be reported separately from annotation burden. A contextual pair is never
presented as an object-language Sigma term.

The supported comparison is between universally interpreted source judgments,
not between a native equality theorem and an arbitrary-model theorem. Exact
source recipes and selected identity terms are retained; equality of scalar
observations or mere inhabitation is insufficient. Source equality, object Id,
Lean equality and family-presentation comparisons retain their separate roles.

No higher-capability claim is evaluated. The source-only higher evidence from
#316 does not pass the concrete interpretation gate. This experiment cannot
close that gate, retire all old Typed clients or validate human usability.
#107 remains paused and #108's separately gated theorem is neither selected nor
prepared here. A new support operation or interface repair requires a new
interface freeze before new held-out selection.
