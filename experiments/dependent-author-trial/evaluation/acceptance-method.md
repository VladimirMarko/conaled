# Replay and statement acceptance

This applies the frozen task contract after an author stops. It adds no new
author obligation and permits the explicit declaration mapping allowed there.

1. Close author work through root, then copy the full attempts directory and
   retain hashes for every file, including commands, failed sources and raw
   stdout/stderr. Verify each archived source against its recorded digest and
   inspect any manifest/source-change rejection. Keep author-reported activity
   distinct from the raw checker evidence.
2. Replay the exact final bytes under the same frozen handoff, using a new
   coordinator attempt name. Attribute this invocation to replay, not author
   work. Verify that the public manifest and compiled project closure still
   match the prospective inventory. No repair changes enter the original file.
3. Inspect every required declaration (or its submitted mapping), its elaborated
   type and its dependencies. Confirm arbitrary source inputs and finite tails,
   both arbitrary substitutions, actual dependent weakenings, selected p and J
   certificate, family equations, source conversion and interpreted validity.
   The baseline must retain its generated source obligations and checked
   interpretation; the candidate must interpret under satisfied Ω and embed the
   actual derivation into Sigma. Reject extra assumptions of the desired output
   or comparison. Mere name existence and Lean exit are not statement coverage.
4. Check the selected recipe explicitly against the private reference: J motive
   Id_Q(p,p), reflexive pulled-back branch, and its exact selected expression and
   annotations. Typed probes or definitional equality checks may use the private
   references after author work closes. Such evaluator code is separate from
   the author's exact source and cannot repair it. Equivalent binder organization
   or helper names are allowed when the mathematical statement is unchanged.
5. Copy the accepted bytes to their integrated module paths with no content
   changes. Rebuild the public entrypoint and apply the exhaustive project axiom
   audit to every mathematical declaration, including private helpers and generated
   auxiliaries. Run the required audit fixtures and candidate verification.
   Record source and destination digests to make byte preservation reviewable.
6. Report pass, partial, fail or unavailable for each requirement and each arm.
   Classify burdens by mathematics, model-builder coherence, source interface or
   presentation, host encoding, and documentation. Separate reference/preparation,
   author work and any assisted/coordinator continuations. Independent Standards
   and Spec review covers this assessment and the retained evidence.

No source or interface repair is silently scored as unaided success. An
interface change requires a new round with a refreeze and new held-out task.
The resulting adopt/revise/repair/defer decision has only the tested scope;
this sample cannot establish a causal productivity or human-usability result.
