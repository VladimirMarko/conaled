# Compositional verified programs

Shared vocabulary for the monorepo's mathematical domains and their verified
programs.

## Language

**Application**:
A domain development that connects mathematical specifications to program
representations through compositional correctness proofs. FRP is an existing
application; orbifold simulation is a proposed application.
_Avoid_: Subproject when referring to this domain boundary.

**Application library**:
The reusable definitions, operations, and proofs developed for an application.
An application can have several alternative implementations.
